# Phase 5 — Passive-Aggressive Roast and Accountability Challenge (budget: 25 min)

## Steps
1. `features/accountability/roast_bank.dart`: ~15 local fallback roasts (funny, passive-aggressive, target the evidence not the person,
   no profanity). Pick randomly but never repeat the last one.
2. `roast_card.dart`: paper-note style card, slight rotation, "NOPE" stamp animation, drops in with a bounce; screen shake (≤ 6 px, 400 ms) + medium haptic.
3. Challenge model + logic for three kinds:
   - `retype`: type a one-sentence commitment; validate character by character with animated correct/incorrect feedback.
   - `quiz`: 2 quick questions generated by the model about the task's own subject (generate with the router; local fallback questions if the call fails).
   - `reupload`: countdown to submit stronger evidence.
4. `challenge_screen.dart`: circular countdown ring (CustomPainter, continuous animation), color shifts in the last 10 s, success burst on completion.
5. **Task locking**: on `partial`/`fail`, set `status = locked`; the Submit button on that task is replaced by the challenge card until it is completed.
   Other tasks show a small "unresolved accountability" badge. Completing the challenge unlocks a new evidence attempt.
6. **Integrity Score and streak**: +10 on a verified pass, −5 on a fail, small bonus for finishing a challenge fast. Animated number counter in the list header.
7. Ensure the roast works offline (local bank) so the demo never dead-ends.

## Exit criteria
- Full loop works: weak evidence ⇒ roast ⇒ locked ⇒ challenge ⇒ unlocked ⇒ stronger evidence ⇒ pass ⇒ completed.
- `flutter analyze` clean. Commit: "phase 5: roast and accountability challenge".
- Update docs and `features/accountability/README.md`.
